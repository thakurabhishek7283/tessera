# Kit catalog

Kits are separate repositories. Each has a playground deployed to GitHub Pages that works without a server.

| Kit | Package | Repository | What it adds |
| --- | --- | --- | --- |
| Rich text editor | `@tessera-kit/editor` | [tessera-workspace](https://github.com/thakurabhishek7283/tessera-workspace) | Tiptap-based editor, form-associated, with Markdown import/export. |
| Sticky notes | `@tessera-kit/notes` | [tessera-workspace](https://github.com/thakurabhishek7283/tessera-workspace) | A free-form board of draggable notes. |
| Kanban | `@tessera-kit/kanban` | [tessera-workspace](https://github.com/thakurabhishek7283/tessera-workspace) | Boards, columns, cards, drag and drop that works from the keyboard, undo/redo. |
| Presence | `@tessera-kit/presence` | [tessera-realtime](https://github.com/thakurabhishek7283/tessera-realtime) | Who is here and what they are doing. |
| Chat | `@tessera-kit/chat` | [tessera-realtime](https://github.com/thakurabhishek7283/tessera-realtime) | Rooms and direct messages, replies, reactions, read receipts. |
| Video | `@tessera-kit/video` | [tessera-realtime](https://github.com/thakurabhishek7283/tessera-realtime) | Peer-to-peer calls for up to six people. |
| Comments | `@tessera-kit/comments` | [tessera-realtime](https://github.com/thakurabhishek7283/tessera-realtime) | Threads and ratings on anything. |
| Annotator | `@tessera-kit/annotator` | [tessera-visual](https://github.com/thakurabhishek7283/tessera-visual) | Draw on images; whiteboard mode. |
| Maps | `@tessera-kit/maps` | [tessera-visual](https://github.com/thakurabhishek7283/tessera-visual) | MapLibre maps with markers and a location picker. |
| Server | tessera-server | [tessera-server](https://github.com/thakurabhishek7283/tessera-server) | WebSocket hub, document store, uploads and ICE credentials. |

Examples for plain HTML, React, Angular, Vue and Next.js are in [tessera-examples](https://github.com/thakurabhishek7283/tessera-examples). [Campside](https://github.com/thakurabhishek7283/campside) is a campsite booking and gear shop built only by composing the kits.

::: info Work in progress
The repositories above are being built in the order: core, server, workspace, realtime, visual, examples, Campside. Links to a repository that has not been published yet will not resolve.
:::
